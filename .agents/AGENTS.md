# Me Time We Time Workspace Instructions

## Automatic Live Deployments
- Whenever code changes are made in this repository, you must automatically:
  1. Commit and push the changes to GitHub (`git add .`, `git commit`, `git push`).
  2. Trigger a live production deployment using Vercel CLI by running `cmd.exe /c npx vercel --prod --yes`.
- This ensures the client's website (https://www.mtwtravel.com) is always updated live. Do not ask for permission before deploying.
